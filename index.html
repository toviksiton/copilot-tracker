WhatsApp Integration
Send field notes directly from WhatsApp to Day to Day Intelligence — no copy-paste needed. Uses Twilio's WhatsApp sandbox.
Webhook URL
Setup (2 minutes):
1. Go to console.twilio.com → Messaging → Try it Out → Send a WhatsApp message
2. Follow the sandbox join instructions (send a code to the Twilio number)
3. In "When a message comes in", paste the Webhook URL above
4. Set Method to HTTP POST and save
5. Add TWILIO_AUTH_TOKEN as a Worker secret for security (optional but recommended)
6. Send any field note from WhatsApp — it auto-appears in Day to Day Intelligence
