Sign in with your Microsoft account to save and load data directly from your OneDrive. The file is stored as copilot-tracker-data.json in your OneDrive root.

Need a Client ID? How to register an Azure app →
Steps to register an Azure app (one-time setup):
1. Go to portal.azure.com → Azure Active Directory → App registrations
2. Click New registration, give it any name
3. Under "Supported account types" choose Any organizational directory and personal Microsoft accounts
4. Under "Redirect URI" choose Single-page application (SPA) and enter this page's URL
5. Click Register, then copy the Application (client) ID and paste above
